# Steelman

Read an argument at its best before judging it. The point is not to defend the
piece or to attack it, but to see what it actually claims and what holds it up.

## Access

Use the Curio MCP tools (`mcp__curio__*`) or the CLI. See `curio-mcp`.

## Process

1. **Read it.** `read_passage` across the piece. If a claim is spread over several
   sections, read all of them before you state it.

2. **Separate claim from evidence.** What is asserted, and what is shown? List
   the assertions that carry the argument, each with its span.

3. **State the strongest version.** Write the argument as a fair opponent would
   make it, even if the author did not. Same conclusion, better construction.

4. **List the load-bearing assumptions.** Which one, if false, takes the whole
   thing down? That is the one that matters.

5. **Name the weakest link and the strongest.** Cite the lines for both.

6. **Verdict.** Does it hold? Say so plainly. A steelman that finds every argument
   equally flawed is not reading, it is a tic.

## Rules

- No strawman. Quote the author's actual words, not a convenient version.
- The strongest version may be better than the one on the page — that is the
  point.
- Distinguish "wrong" from "unsupported". Most weak arguments are the second.
- Cite the span for every claim, both the ones you strengthen and the ones you
  cut.
